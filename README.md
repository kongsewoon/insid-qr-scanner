# InSID QR 수신기 (단독 PWA)

스냅샷 QR 반출의 수신측 스캐너. **서버 없이 폰 단독으로 동작**한다.

## 왜 별도 정적 페이지인가

- 폰 브라우저의 카메라 API(getUserMedia)는 **https 에서만** 열린다. 폐쇄망 insid-web(http)의
  `/snapshot/mobile` 은 폰에서 카메라를 못 켠다 — 외부 https 스캐너를 쓰던 이유.
- 이 페이지는 순수 클라이언트(수신 데이터가 어디로도 전송되지 않음)라 공개 호스팅해도 안전하다.

## 배포

아무 https 정적 호스팅에 이 디렉토리 4파일 + `jsqr.min.js` 를 올리면 끝.
기존 `seunghee-han.github.io/QR_Scanner` 저장소 내용을 이 디렉토리로 교체하는 것을 권장.

## 사용

1. 폰에서 배포 URL 접속 → 브라우저 메뉴 "홈 화면에 추가"(PWA 설치).
2. **설치 후에는 인터넷 없이(비행기모드) 동작** — service worker 가 전체를 캐시.
3. 시작 → 송신 화면의 정보 QR부터 스캔 → 진행률/누락 확인 → 완료 시 sha256 검증 + 저장.
4. 누락이 남으면 표시되는 런레인지("1, 204-207")를 송신 화면 '누락 재송출' 칸에 입력.

## 엔진

- Android/Chrome: `BarcodeDetector` (멀티 QR 동시 인식 — 2×2 배열 대응, 프레임당 전부 수집)
- iPhone/미지원 브라우저: `jsQR` 폴백 (전체 프레임 ↔ 사분면 크롭 교차 스캔으로 배열 대응)

## 포맷 정합

파서는 `web/frontend/src/lib/snapshotQr.ts`(ISQ1/ISQ2)와 동일 로직의 포팅이다.
**포맷 변경 시 양쪽을 함께 갱신할 것.** 헤드리스 검증: 실제 스냅샷 청크로
파싱→재조립→sha256 일치 확인(2026-07-29, q85 280청크 PASS).
